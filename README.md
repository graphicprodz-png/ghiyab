# غياب — إعلام الأولياء بغياب التلاميذ

تطبيق ويب للمؤسسات التعليمية: المشرف يسجّل غياب التلاميذ في كل حصة (بالضغط على الاسم أو بمسح الكودبار)، وبعد مهلة يحددها المدير تُرسل المنصة **آلياً** رسالة واتساب أو SMS لولي التلميذ:

> السلام عليكم ورحمة الله،
> نعلم وليّ التلميذ(ة) سلمى محمدي (رقم 260002، قسم 2 ثانوي — علوم تجريبية 1) أن ابنكم/ابنتكم غائب(ة) عن حصة الرياضيات مع الأستاذ(ة) محمد بوعلام يوم 02/11/2026 من الساعة 08:00 إلى الساعة 09:00.
> إدارة ثانوية النموذجية

## المزايا

- **الأقسام والتلاميذ:** إضافة يدوية أو لصق قائمة كاملة من Excel (الاسم، الولي، الهاتف).
- **رقم وكودبار تلقائي** لكل تلميذ (Code 39) مع صفحة ملصقات جاهزة للطباعة تُلصق في الدفتر اليومي.
- **تسجيل الغياب:** المشرف يبدأ الحصة (القسم، المادة، الأستاذ، التوقيت) ثم يضغط على الغائبين، أو يمسح الكودبار بقارئ USB/بلوتوث، أو بكاميرا الهاتف (Chrome على أندرويد).
- **إرسال آلي** بعد المهلة (15 دقيقة افتراضياً) مع إعادة المحاولة 3 مرات، وإمكانية مزوّد احتياطي (مثلاً واتساب ثم SMS).
- **وضع يدوي** بدون أي اشتراك: الرسالة تظهر جاهزة وتُرسل بضغطة على زر واتساب أو SMS.
- **حسابات وصلاحيات:** الإدارة (كل شيء) والمشرف (تسجيل الغياب ومتابعة الإشعارات).
- يمكن إلغاء غياب سُجّل خطأً ما دام الإشعار لم يُرسل.
- **بدون أي مكتبة خارجية:** Node.js وحده يكفي (قاعدة البيانات SQLite مدمجة فيه).

## التشغيل على جهازك

يلزم **Node.js 22.13 أو أحدث**.

```bash
git clone https://github.com/graphicprodz-png/ghiyab.git
cd ghiyab
cp .env.example .env      # ثم عدّل ADMIN_PASS وبقية الإعدادات
npm start
```

افتح `http://localhost:3000` وادخل بحساب المدير. إذا لم تضع `ADMIN_PASS` تظهر كلمة مرور عشوائية في الطرفية عند أول تشغيل.

لا يحتاج `npm install` لأن التطبيق لا يعتمد على أي حزمة خارجية.

## النشر على الإنترنت

التطبيق يحتاج خادماً يعمل باستمرار (لأن الإرسال الآلي يجري في الخلفية) وقرصاً دائماً لقاعدة البيانات.

### على خادم VPS بـ Docker (الأنسب)

```bash
docker build -t ghiyab .
docker run -d --name ghiyab --restart unless-stopped -p 3000:3000 \
  -v ghiyab-data:/data --env-file .env ghiyab
```

ثم ضع أمامه Nginx أو Caddy مع شهادة https، واجعل `COOKIE_SECURE=1`.

### على Render أو Railway

1. اربط المستودع من GitHub وأنشئ خدمة Web Service بـ Docker.
2. أضف **قرصاً دائماً (Persistent Disk / Volume)** مركّباً على `/data`، وإلا ستُمحى البيانات عند كل إعادة تشغيل.
3. أضف متغيرات البيئة من `.env.example` في لوحة الخدمة.

> GitHub Pages لا يصلح وحده لأنه يستضيف صفحات ثابتة فقط، بلا خادم ولا قاعدة بيانات.

## إعداد الإرسال الآلي

يُختار المزوّد بالمتغير `NOTIFY_PROVIDER` (التفاصيل في `.env.example`).

| الخيار | الكلفة | ملاحظات |
|---|---|---|
| `manual` | مجاني | لا إرسال آلي؛ يضغط المشرف أو الإداري زر واتساب/SMS |
| `http` + هاتف أندرويد | رصيد شريحة المؤسسة فقط | تطبيق بوابة SMS على هاتف أندرويد (مثل SMS Gateway for Android) يرسل من شريحة Mobilis/Djezzy/Ooredoo العادية |
| `whatsapp_cloud` | حسب تسعيرة Meta لكل محادثة | يتطلب حساب WhatsApp Business ورقماً مخصصاً وقالب رسالة معتمداً |
| `twilio_sms` / `twilio_whatsapp` | مدفوع لكل رسالة | سهل الإعداد، أغلى نسبياً للجزائر |

### بوابة SMS عبر هاتف أندرويد (`http`)

1. ثبّت تطبيق بوابة SMS على هاتف أندرويد فيه شريحة المؤسسة واجعله متصلاً بالإنترنت والشحن.
2. خذ من التطبيق عنوان الإرسال (URL) واسم المستخدم وكلمة المرور.
3. اضبط:
   ```
   NOTIFY_PROVIDER=http
   HTTP_URL=<عنوان الإرسال من التطبيق>
   HTTP_AUTH=Basic <base64 لـ user:pass>
   HTTP_BODY={"phoneNumbers":["{phone_plus}"],"message":"{message}"}
   ```
4. **تحقق من صيغة `HTTP_BODY` في توثيق التطبيق الذي تختاره**، فأسماء الحقول تختلف من تطبيق لآخر. المتغيرات المتاحة: `{phone}` و`{phone_plus}` و`{message}`.

### WhatsApp Cloud API

أنشئ في WhatsApp Manager قالب رسالة من فئة Utility بالعربية يحتوي متغيراً واحداً، مثلاً:

```
إشعار غياب: {{1}}
```

وبعد اعتماده ضع اسمه في `WA_TEMPLATE` مع `WA_TOKEN` و`WA_PHONE_ID`. يُدمج نص الإشعار كاملاً في المتغير `{{1}}`.

- أرقام الهاتف المحلية (`0550…`) تُحوّل تلقائياً إلى الصيغة الدولية برمز الدولة المحدد في الإعدادات (213 افتراضياً).
- يجب الحصول على موافقة الأولياء على استقبال الإشعارات، وحماية بيانات التلاميذ وفق القوانين المعمول بها.
